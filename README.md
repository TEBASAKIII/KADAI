1. ターミナルで以下の命令を入力, mongoDBを起動します.

docker run --rm --name=my-app-db -p 27017:27017 mongo


2. 適切なアドレスに移動し, 以下の命令を入力してサーバを起動します.
   nodemonを使用しているため, ファイル変更後もサーバの再起動は不要です.

npx nodemon app.js


3. ブラウザで http://localhost:3000/ を開きます.

4. 「体重記録」部分で「年月日」「体重」をそれぞれ入力後、送信ボタンを押します。
   体重は数値以外は入力不可です。

5. ページを更新します.
   「体重記録」「体重グラフ」部分にそれぞれ入力した値が反映されていれば成功です。

6. 「体重記録」部分に反映された体重にカーソルを合わせると、「削除」ボタンが表示されます。
   ボタンを押した後ページ更新すると、「体重記録」「体重グラフ」ともに削除命令が反映されています。
